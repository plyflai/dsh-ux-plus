## 功能详解

### 对话字号与宽度

对话区字号默认 14px，长回答密集时可以在 **设置 → 通用 → 对话区** 单独调大字号、收窄阅读宽度——只作用于会话内容，不改整个界面。

### 会话菜单：复制会话 ID 与继承对话

每个会话行右侧的三点菜单里，本插件追加两项（位于置顶、重命名等原生项之前）：

- **会话 ID**：点击即把该会话的 ID 复制到剪贴板，用于 `--session` 续接、日志定位等场景。
- **继承对话**：见下。

### 继承对话

点击「继承对话」后，会在点击位置弹出一个轻量的模型选择浮层，列出当前可路由的全部模型（按提供方分组）：

选定模型后，插件会：

1. 在**原会话所属的工作区**里创建一个全新会话；
2. 把新会话的模型切换为刚选中的那个；
3. 向新会话投递一条继承提示词——内容是被继承会话的 session ID，加上「总结并继承这个对话的进度，越近轮次的对话所投放的注意力要越多」；
4. 自动跳转到新会话，模型开始读旧会话、输出进度总结并接着推进。

适合这些场景：一个会话跑得太长想换个更贵的模型收尾；某个提供方限流想换条路继续；或者单纯想把进展"移植"到另一个模型的上下文里。原会话完全不受影响，「会话 ID」复制也原样保留。

### 最近活动排序（分区 · 状态点 · 闲置收起）

最近聊过的工作区分组和组内会话自动排到前面，多个项目同时推进也能快速回到刚才的工作；只改视觉顺序，宿主的排序设置与数据不动。

在时间之上，会话行被分成**两个区**，判据只有一条：最后活动时间。正在运行、或 24 小时内动过的会话属于 **Active 区**——区内按活动时间倒序，整块铺一层连续的淡绿底、外沿圆角。会话行刻意做紧凑——26px 行框、13px 标题，比宿主的 32px / 14px 更紧，长列表读起来像侧栏而不是一叠卡片；Active 区靠底色与状态点区分，不靠把行撑高。每行行首是它自己的**状态点**（与宿主同一信号）：等待回复是橙色呼吸点，运行中是转圈的蓝色圆环，未读完成是绿色实心点。没有别的标准——等待回复超过一天的会话，一样是休眠会话。

**不额外加折叠行**（用户规则）：本功能不再放自己的细条——宿主的【展开其余 N 个会话】就是唯一的展开入口，两套系统共用这一个按钮。有 Active 块、且宿主放出了这个按钮的工作区，历史在 Active 块下面整体隐藏（行还在 DOM 里，只是收起来），按钮钉在 Active 块正下方（Active 里有几条都钉得住）——点第一次之前只看得到 Active 块。点一次即展开、列表交还宿主——渲染出的每一行都保持可见、绝不回弹，按钮同时回到宿主原生的位置（所有会话的最下方），展开态看起来和宿主原生列表一模一样；点【收起】再次折回，绿底块与按钮钉位一起回来。整个工作区都在休眠、或宿主没有放出这个按钮时，工作区表现和原生完全一致。展开后的行不会自己回到 Active 区，除非它真的有了新活动。

工作区标题用最多三颗**纯色点**（待回复 / 未读 / 运行中）表示 Active 区里被藏住的注意力——工作区被收起或撞上宿主 5 条限额时；计数文本保留在 tooltip（「2 待回复 · 1 未读」）供悬停与读屏。休眠区的状态永不上浮到标题，有运行中或等待回复会话的工作区不会被闲置自动收起。

重排不会和你抢鼠标：指针停在会话树内或有菜单打开时暂停（推迟、不丢弃，由两个有上限的重试定时器兜底，绝不因为等不到某个事件就永远不补算，而且这次暂停本身有寿命——两次重试用完后，哪怕指针还停在列表里也会照常补算一次，被推迟的东西不会一直停在旧状态）；行位置变化带短促的 FLIP 过渡（`prefers-reduced-motion` 下自动关闭），跨区移动同样如此；分区还会跟随一个心跳定时重算一次：即使数据层没有任何变化，会话也会在跨过 24 小时线时自动入眠；有运行中 / 待回复会话的工作区，分组同样会上浮。**你自己的操作会穿透这次暂停**——切换宿主的视图选项（分组方式 / 排序方式 / 筛选会话），或点击宿主的【展开其余 N 个会话】，重绘与点击同帧完成、不带 FLIP，不再等指针离开列表。另外，如果某个工作区在这一瞬间看到自己解释不了的行数（宿主先渲染出新的行、数据稍后才到），它会保持上一次自洽的样子——底色与折叠一起保留，而不是在这一瞬间把 Active 区的绿底撤掉；只有本功能确实建模不了的形态，才会把该工作区交还给宿主。

同一个功能还负责**闲置瘦身**：工作区超过 **24 小时**没有任何实际活动（空会话与子代理会话不算，与排序同一口径）后，会在打开页面时自动收起一次；同时每个工作区行右侧显示距今未更新的时间标——刚刚 / N分钟 / N小时 / N天 / N个月 / N年，样式与宿主会话行的时间完全一致，默认透明，鼠标悬停在该行时淡入，菜单打开时让位给操作按钮。

自动收起对每个工作区每次打开页面最多触发一次：手动重新展开后，不会再被反复收起。没有会话（或只有空会话 / 子代理会话）的工作区没有活动信号，不打标、不收起。时间标跟随 DSH 语言与明暗主题。会话状态服务不可用时，整个功能降级为纯时间排序：没有分区、没有状态点。

### 标签页注意力指示灯

标签页图标仍是宿主的白鲸——本功能只在有事可说的时候给它上色、让它呼吸、或加一颗点。三个信号**互相独立**、可自由组合：一条缓慢渐隐渐显的绿鲸 + 闪烁橙点，就是「有跑完没看 + 有东西等你点 + 还有会话在算」的画面。

| 标签页在说 | 含义 |
| --- | --- |
| 白鲸**呼吸**（缓慢渐隐渐显） | 任意被统计的会话在计算（等你点的会话不算在算——那是橙点的戏） |
| **绿鲸** | 有跑完的会话还没被打开——工作区列表亮绿点时它才绿，严格一致 |
| **橙点闪烁** | 有东西在等你点（审批、提问、计划确认） |
| 原样白鲸 | 什么事都没有；宿主的图标原样还回去 |

呼吸是真正的渐隐渐显——3.6 秒一条 20 fps、72 帧的余弦曲线，不是闪烁——透明度有 35% 的下限；闪烁刻意做成不对称（三帧里亮两帧）。浏览器会把后台标签页的定时器钳到约每秒一跳：橙点在后台改为每跳换一帧——慢而稳定的闪烁——无论冻在哪一帧，提醒都仍然可见；切回标签页的瞬间，周期从可见帧重新开始。子代理与空会话永不点亮标签页——一堆子代理不该把白鲸永久染成橙色。宿主 favicon 的明暗两套主题都保留（绿鲸染的是当前主题那条鲸）；读不到宿主图标文件、或鲸鱼染不了色时，本功能静默不做事。关掉开关即摘除覆盖链接与定时器，不留残留。

## 安装

需要 Node.js ≥ 22、PATH 中的 pnpm，以及一个 DSH Web profile。

```bash
dsh plugin --profile <name> add github:plyflai/dsh-ux-plus
```

安装后重启该 profile。打开 **设置 → UX Plus**，即可按需开关各项功能。功能默认开启，单项开关即时生效。

对话字号和宽度在 **设置 → 通用 → 对话区** 调整。

## 兼容性

- 仅面向 DSH 的 **Web 界面**（浏览器），不适用于终端 TUI。
- 所有功能都是宿主公开扩展点（侧边栏插槽、设置表单、DOM 微调）上的挂载，不修改宿主源码；任何一项都可以在设置里单独关闭。
- 宿主升级可能调整内部 DOM 与插槽契约；如遇失效请提 issue，通常会随版本跟进。

## 开发

```bash
npm install
npm test        # node --test，含构建产物与注入依赖的静态断言
npm run build   # tsdown 产出 lib/client.js（经典脚本，随仓库提交）
```

- 每个功能是一个 `features/<name>/` 私有模块（host + client 两半），在 `src/index.js` 与 `src/switches.js` 的功能清单里注册，不是独立插件。
- 客户端资源打包为单个经典脚本注入 `window.__ModuleLoader__`，外部依赖被严格限制在宿主提供的模块种子内，构建脚本会校验。
- 每次推送到 main 会在下方更新记录追加一条，并同步 [CHANGELOG.md](CHANGELOG.md)。

## 更新记录

最近三条；完整历史见 [CHANGELOG.md](CHANGELOG.md)。

- **v0.4.0 · 2026-10-17** — 新功能「标签页注意力指示灯」：标签页的白鲸 favicon 保持原形，叠上三个互相独立、可同屏的信号——任意会话在算白鲸就缓慢渐隐渐显地呼吸（3.6 秒一条余弦曲线，不是闪烁）、工作区列表有绿点（跑完没看）时整条鲸鱼变绿、有东西等你点时橙点闪烁。闪烁做成不对称、呼吸有 35% 下限，所以后台标签页被定时器节流后、无论停在某一帧提醒仍可见；后台的橙点每个节流跳换一帧（约每秒一切换——这是 Chrome 的下限），切回标签页的瞬间从亮帧重启周期；子代理与空会话永不点亮标签页；宿主明暗两套主题都保留，关掉开关即摘除覆盖不留残留。另修复：点击【N 条历史会话】后列表闪烁一下——回答这次点击的重绘现在等宿主的 200ms 行滑翔落定再化妆；侧栏自己的折叠细条整个退役——宿主的【展开其余 N 个会话】成为唯一展开入口：历史在 Active 块下面整体隐藏，按钮钉在 Active 块正下方；点一次展开（按钮回到所有会话最下方）、点【收起】再次折回。
- **v0.3.2 · 2026-10-16** — 修复：Active 区的绿底会在使用过程中突然消失。两个原因——某次重绘撞上它解释不了的行数时会把绿底整块撤掉（紧凑行框、状态点、顺序都还留着，所以只有绿底不见了），而防打扰暂停又让补算的重绘一直推迟到指针离开列表为止。现在工作区在宿主「先渲染、数据后到」的短暂竞态里保持上一次自洽的样子（底色与折叠一起保留），只有真正建模不了的形态才交还宿主；暂停也有了寿命——两次重试用完就照常补算一次，且额度只由「暂停解除」刷新，不由穿透过暂停的那次重绘刷新。
- **v0.3.1 · 2026-10-16** — 修复：指针停在会话列表里时，点击「N 条历史会话」细条没有反应——防打扰暂停把点击自己引发的那次重绘一并吞掉了，藏起来的行要等指针离开列表才回来。现在用户操作会穿透暂停（点细条、切换宿主视图选项都在点击当次重绘），被暂停推迟的那次重绘也由两个有上限的定时器兜底重试，不再等一个可能永远不来的事件。
