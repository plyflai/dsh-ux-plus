## 0.5.0 新增 — 省掉「先开工作区」那一步

只是想快速查个东西，却要先建一个工作区、还得给它起个名字——这一步现在没了。侧边栏【自动化任务】下面常驻一个搜索框：输入、回车，开的就是一模一样的会话界面；会话自己收进一个隐藏工作区，不占你的侧边栏。

- **少三次操作**：不用新建工作区、不用起名字、不用挑目录——想到什么直接问、直接搜
- 左边放大镜，右边一个极小的模型选择器（不改就按宿主默认模型走）
- 再右边时钟图标 = 历史：最近 50 次搜索，点一条就回到那次会话
- 隐藏工作区在主目录下的 `.dsh-ux-plus/search`，首次使用自动建，侧边栏看不见

## 功能详解

### 工作区快速搜索

侧边栏【自动化任务】下方常驻一个搜索框，省掉「先建工作区」这一步：想到什么就直接问、直接搜——输入、回车，开的是一个普通会话（界面和普通会话完全一致），会话自己收进隐藏工作区，不占侧边栏。

![搜索框常驻在工作区列表上方：左侧放大镜，右侧模型、历史、会话气泡三个图标，空态是一行斜体淡显的提示](docs/images/quick-search.png)

| 元素 | 行为 |
| --- | --- |
| 搜索框（放大镜在左） | 回车直接搜索（单行输入框）；输入法选词时的回车不会误提交 |
| 模型选择器 | 右侧一枚小图标（芯片），点开就是模型列表（当前项打勾）；不改就用宿主默认模型；选了非默认模型时图标带一个小圆点，并记在本机 |
| 会话气泡（最右） | 点一下回到最近那个搜索会话——跑没跑完都能回；有搜索正在跑时气泡里亮起一个点并轻微呼吸，没有数字；还没有搜索会话时是暗的、点不动 |
| 时钟图标（右侧） | 打开历史：最近 50 次搜索，点一条直接回到那次会话，可一键清空 |
| 侧边栏 | 搜索会话**不出现**——它们都在隐藏工作区里 |

- 隐藏工作区在你主目录下（`.dsh-ux-plus/search`），首次使用自动创建；它不进工作区列表、不进会话树，但历史弹窗能把你带回任何一个旧会话。
- 搜索框只在侧边栏展开时出现；侧边栏收成窄栏（rail）时它自己让位。
- 关掉这个开关，隐藏工作区的规则一起撤掉——那些会话会照常出现在侧边栏里，不丢东西。

输入、回车，就是一次搜索会话：

![在框里输入一句问题，右侧三个图标不变，回车即开一个普通会话](docs/images/quick-search-typed.png)

搜索在跑时，最右那个气泡里亮起一个点；点它回到最近那个搜索会话，跑完、答案出来了，也还是这一下。

### 标签页注意力指示灯

图标仍是宿主的白鲸——本功能只在有事时给它上色、让它呼吸、或加一颗点。

| 标签页在说 | 含义 |
| --- | --- |
| 白鲸**呼吸**（缓慢渐隐渐显） | 任意被统计的会话在计算 |
| **绿鲸** | 有跑完的会话还没被打开——与工作区列表的绿点严格一致 |
| **橙点闪烁** | 有东西在等你点（审批、提问、计划确认） |
| 原样白鲸 | 什么事都没有；宿主图标原样还回去 |

呼吸有 35% 透明度下限、闪烁刻意不对称，后台标签页被节流到约每秒一跳时提醒依然可见；切回标签页的瞬间从可见帧重启周期。子代理与空会话永不点亮标签页。明暗两套主题都保留；染不了色时静默不做事。关掉开关不留残留。

### 最近活动排序

最近聊过的排最前，回到刚才的项目不用翻。只改视觉顺序，宿主的排序设置与数据不动。

**Active 区。** 运行中、或 24 小时内动过的会话，收进一整块连续的淡绿底：26px 紧凑行，行首是状态点——橙色呼吸（等你回复）、蓝色转圈（运行中）、绿色实心（跑完没看）。工作区标题用最多三颗纯色点提示被藏住的注意力，计数在 tooltip 里。

**历史整体隐藏。** 不加自己的折叠行——宿主的【展开其余 N 个会话】就是唯一入口，钉在 Active 块正下方。点一次展开：每一行出现，按钮回到列表最下方，看起来和宿主原生展开一模一样；点【收起】再次折回。

**闲置瘦身。** 超过 24 小时没动的工作区在打开页面时自动收起一次，悬停显示距今时间（刚刚 / N分钟 / N小时 / N天）。有运行中或待回复会话的工作区不会被自动收起。

重排不跟你抢鼠标：指针在列表里或有菜单打开时暂停，而你自己的操作（切视图选项、点展开按钮）在点击当帧直接重绘。行位置带短促滑翔（`prefers-reduced-motion` 下关闭），分区按定时心跳重算（跨过 24 小时线自动入眠），宿主渲染竞态下保持上一次自洽的样子、不闪。

### 对话字号与宽度

对话区默认 14px。在 **设置 → 通用 → 对话区** 单独调大字号、收窄阅读宽度——只作用于会话内容，不改整个界面。

### 会话菜单：复制会话 ID 与继承对话

每个会话行的三点菜单追加两项（在置顶、重命名等原生项之前）：

- **会话 ID** — 一键复制到剪贴板，用于 `--session` 续接、日志定位。
- **继承对话** — 点击位置弹出模型选择浮层。选定后：同工作区新建会话、切到所选模型、投递继承提示词（总结并接着推进，越近的轮次权重越高）、自动跳过去。原会话完全不受影响。适合长会话换更贵的模型收尾、或提供方限流时换条路继续。

### 提问结果默认展开

`ask_user_question` 卡片结束后，问题和答案保持展开——回看决定少一次点击。

### 设置

**设置 → UX Plus**：六项功能独立开关，默认全开，切换即时生效。

## 安装

需要 Node.js ≥ 22、PATH 中的 pnpm，以及一个 DSH Web profile。

```bash
dsh plugin --profile <name> add github:plyflai/dsh-ux-plus
```

安装后重启该 profile。开关在 **设置 → UX Plus**（默认开启、即时生效）；对话字号和宽度在 **设置 → 通用 → 对话区**。

## 兼容性

- 仅面向 DSH 的 **Web 界面**（浏览器），不适用于终端 TUI。
- 所有功能都挂在宿主公开扩展点上，不修改宿主源码；任何一项都可单独关闭。
- 宿主升级可能调整内部 DOM 与插槽契约；如遇失效请提 issue。

## 开发

```bash
npm install
npm test        # node --test，含构建产物与注入依赖的静态断言
npm run build   # tsdown 产出 lib/client.js（经典脚本，随仓库提交）
```

- 每个功能是一个 `features/<name>/` 私有模块（host + client 两半），在 `src/index.js` 与 `src/switches.js` 的功能清单里注册，不是独立插件。
- 客户端资源打包为单个经典脚本注入 `window.__ModuleLoader__`，外部依赖严格限制在宿主提供的模块种子内，构建脚本会校验。
- 每次推送到 main 会在下方更新记录追加一条，并同步 [CHANGELOG.md](CHANGELOG.md)。
